# CrossApp 
Наскрізний проєкт з крос-платформного програмування. 
Предметна область: Склад. Сутності: Product (товар), StockBatch (партія), Warehouse (склад), Movement (переміщення) 
Призначення: облік залишків товарів по партіях.

## Структура рішення
- `src/Core` — спільна бібліотека класів (домен, моделі, збір даних про середовище)
- `src/Cli` — консольна точка входу

## Порівняння режимів публікації

| RID | Режим | Розмір каталогу publish | Потрібен встановлений runtime |
| --- | --- | --- | --- |
| win-x64 | self-contained | 76.85 МБ | ні |
| win-x64 | framework-dependent | 0.19 МБ (~196 КБ) | так (.NET 10) |

## Інваріанти доменної моделі (Product)

1. **Ідентифікатор, SKU, назва та одиниця виміру** не можуть бути порожніми або містити лише пробіли (`ArgumentException`).
2. **Початковий залишок** не може бути від'ємним при створенні (`ArgumentOutOfRangeException`).
3. **Кількість для операцій приходу чи видачі** має бути строго більшою за нуль (`ArgumentOutOfRangeException`).
4. **Видача товару зі складу** неможлива, якщо запитувана кількість перевищує поточний залишок (`InvalidOperationException`).

## Сервісний шар та Сховища (Лабораторна 5)

- **ICatalogStore**: Контракт абстракції сховища (CRUD операції).
- **InMemoryCatalogStore**: Зберігання у списку/словнику в пам'яті на основі SampleData.
- **FileCatalogStore**: Кешування у пам'яті з автоматичним збереженням у JSON-файл (`catalog.json`).
- **CatalogService**: Шар бізнес-логіки, який працює лише через інтерфейс `ICatalogStore`.
- **Запуск у файловому режимі**: `dotnet run --project src/Cli -- --file`

## Доменні події та Делегати (Лабораторна 6)
- **CatalogChangedEventArgs**: Клас даних події, що містить Id, тип зміни (`CatalogChangeKind`), дельту та залишок після операції.
- **CatalogService.Changed**: Подія типу `EventHandler<CatalogChangedEventArgs>`, яка піднімається виключно після успішного виконання бізнес-операцій (`Add`, `Receive`, `Issue`).
- **Підписки в Cli**: 
  1. Локальний метод для виводу в консоль та запису в файл логів (`logs/app.log`).
  2. Лямбда-вираз із замиканням зовнішнього лічильника подій.
- **Func-фільтрація**: Метод `FindAll(Func<Product, bool> predicate)` для вибірки сутностей за довільним критерієм.
